# Regras do laboratório

1. Implementar somente a etapa pedida no prompt atual.
2. Não antecipar arquivos, bibliotecas ou abstrações de etapas futuras.
3. Não usar Next.js, Vite, Nx, Turborepo, Tailwind ou biblioteca visual neste laboratório.
4. Manter a interface mínima e sem preocupação estética além de legibilidade.
5. Usar TypeScript estrito; evitar `any`, casts amplos e `@ts-ignore`.
6. Citar toda dependência nova no resumo, com o motivo de uso.
7. Usar versões estáveis e compatíveis; não gravar `latest` no `package.json`.
8. Nunca publicar pacotes no npm público.
9. Não criar commits automaticamente.
10. Ao terminar cada etapa, executar os checks relevantes e criar `docs/lessons/NN-nome.md` contendo:
    - o que foi criado;
    - por que foi criado;
    - fluxo de execução;
    - arquivos importantes;
    - comandos;
    - como validar;
    - erros comuns;
    - três perguntas de revisão;
    - um exercício manual pequeno;
    - uma explicação de entrevista em até 90 segundos.
11. A resposta final de cada etapa deve mostrar:
    - resumo;
    - árvore apenas dos arquivos alterados;
    - dependências adicionadas;
    - comandos executados e resultados;
    - pontos que devem ser revisados no diff;
    - mensagem de commit sugerida;
    - a frase `PAREI NESTA ETAPA`.
